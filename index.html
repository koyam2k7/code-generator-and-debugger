How it works

Four steps, one page — nothing you paste ever leaves your browser.

01Generate

Describe the task in plain words. The generator picks the right pattern for the language and applies your security, reliability, and cost principles.

02Debug & Fix

Paste your code and the error message you hit. It pairs the two — matching the error type and line to the code — scans for 30+ real problems, and rewrites the code with the fixes applied.

03Explain

A line-by-line plain-English walkthrough: what each block does, what runs first, and what could go wrong in production.

04Assess

Scores out of 100 for Security, Reliability, and Cost Efficiency, with every deduction explained and a fix suggested.

What gets checked

These are the failure modes that cause real incidents — leaked credentials, runaway bills, and scripts that work once and break on the second run.

🔒 Security

  • Hard-coded passwords, keys & tokens
  • Public / 0.0.0.0/0 access rules
  • Missing encryption at rest
  • eval, Invoke-Expression & unsafe execution
  • Over-privileged policies & plain-text secrets

🛡 Reliability

  • Missing error handling & retries
  • Network calls with no timeout
  • Non-idempotent tasks that break on re-run
  • Bare except: that hides failures
  • No logging — invisible when it fails at 3am

◈ Cost optimisation

  • Oversized instances with no justification
  • No lifecycle / retention rules on storage
  • Resources with no tags for cost tracking
  • Always-on resources that could be scheduled
  • Expensive storage tiers for cold data
